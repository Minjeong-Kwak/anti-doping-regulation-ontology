# Which classes the competency questions reach

A class stays in this ontology only if a competency question uses it. This report is what makes that principle checkable rather than asserted.

Classes: 57. Reached: 57. Not reached: 0.

A class counts as reached if a question names it, or if an individual of it is bound by a question's solution. Binding is what counts, not printing: a question that joins through a case record reaches that class whether or not it prints it.

Every class is reached.
